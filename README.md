Tech

A single static page built with plain HTML and CSS, with a few lines of JavaScript for the copy-email button. There is no build step and nothing to install. It supports light and dark mode and works on phones.

Run it locally
Download or clone this repository.
Open index.html in any browser.
Deploy on GitHub Pages
Push index.html and this README.md to a public repository.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch, then branch main and folder / (root).
Save, and wait a minute or two for the live link.
Edit the content

All text is inside index.html. Search for the section you want to change, for example id="experience" or id="skills", and edit the text between the tags.
